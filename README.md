#Online Book Store

#Overview

The Online Book Store is a full-stack web application that allows users to browse books, submit reviews, and manage their shopping experience through an intuitive interface. The project also includes an administrative dashboard for managing books, users, and website content.

#Features

#Customer

- Browse available books
- Search books
- Submit reviews
- View book details
- User authentication

#Administrator

- Secure admin login
- Manage books
- Add, edit and delete products
- Manage customer information
- Monitor website content

#Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap

#Database

The application uses MySQL to manage:

- Users
- Books
- Reviews
- Orders
- Administrator accounts


#Installation

1. Install XAMPP.
2. Import the provided SQL database into phpMyAdmin.
3. Update the database connection in `config.php`.
4. Place the project inside the `htdocs` directory.
5. Start Apache and MySQL.
6. Open the project in your browser.
